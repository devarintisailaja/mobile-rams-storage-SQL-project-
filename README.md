# mobile-rams-storage-SQL-project-
SQL project for mobile company, RAM and storage details
## Technologies Used
- MySQL
- SQL

## Project Features
- Mobile company details
- Mobile model details
- RAM details
- Storage details
- Mobile price details
- SQL queries for retrieving mobile information

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- DELETE
- WHERE
- ORDER BY
- GROUP BY
- JOIN
- Primary Key
- Foreign Key

## Project Purpose
This project is created to practice SQL database management and to store and retrieve mobile company, RAM, storage and mobile details.
